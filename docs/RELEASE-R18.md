# r18 — package support (experimental)

Source tag: `experimental-2026.11.11-package-support-r18`.

Это обновление исходников и экспериментальный личный полный комплект. Публичный
релиз не содержит Qualcomm radio blobs и не заменяет старые r15-external assets.
Готовая полная прошивка предоставляется отдельно в приватном репозитории владельца.
Приватность репозитория не меняет лицензии сторонних компонентов и не разрешает
их дальнейшее распространение: см. [licensing](LICENSING.md).

## Главное

- Linux 6.18.60, соответствующий набор WG и AWG 3.1/tools/LuCI.
- veth, TUN, nft/NFQUEUE, расширенные USB/QMI/MBIM/serial зависимости.
- Подписанный автономный комплект пакетов; kernel IPK не включается для фиктивного
  выполнения зависимости на старом ядре. Не устанавливать весь каталог разом.
- Исправлены отключение чужих feeds при восстановлении настроек и MAC provisioning.
- Уточнены проверки основной пары kernel/root перед последующими sysupgrade.
- Включены ранее проверенный uhttpd CGI fix и ограниченное восстановление старта
  включённого радио, если его PHY появился после первоначальной ошибки netifd.

## Что действительно проверено

Один RE-CS-06, primary root 122 MiB: обновление с сохранением настроек/идентичности,
readback образов и защищённых областей, WG/AWG default handshake с пакетами в
изолированных netns, veth/TUN и реальная доставка двум пакетам NFQUEUE consumer.
После поправки радио повторный программный reboot восстановил обе AP, QMI,
HincyRay и большой раздел данных без ручного запуска.

Выкладываемый полный образ пересобирается с этой поправкой. Это не утверждение,
что именно его новый хеш повторно прошит на всех устройствах. Нет новой проверки
cold boot, root 2 GiB, всех модемов, нестандартных AWG-параметров или установки
Zapret/5gmodem на рабочий роутер. [Подробные границы](PACKAGE-SUPPORT-R18.md).
Сообщение о 160 МГц отдельно исследуется: EHT160 AP успешно запущена после CAC,
но клиентская передача на 160 МГц и VHT160 не подтверждены; исправление не заявлено.
[Диагностика](WIFI-160-RU.md).

## Перед обновлением

Только **уже установленная наша OpenWrt на RE-CS-06 с primary p21/p23**. Известны
root 249856 и 4194304 секторов; это не универсальный stock installer и не поддержка
всех устройств с похожим Qualcomm-чипом. Не менять GPT/bootloader/ART и не копировать
чужие MAC/калибровку. Старый helper r15–r17 требует отдельной предварительной оценки.
Сохранить два проверенных backup, собственное состояние дополнений и служебные
файлы `/etc/sysupgrade.conf`. Config backup не содержит автоматически всё ПО.

Публичные assets: архив исходников рецепта, SHA256SUMS и документированные исходные
revisions. Бинарные полные образы, их matching feed и соответствующий исходный
комплект — отдельные приватные assets, без пользовательских конфигураций.
